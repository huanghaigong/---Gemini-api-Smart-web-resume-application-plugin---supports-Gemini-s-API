# 智能网申 · AI 一键填简历（Chrome 扩展）

自动识别各大厂招聘官网的简历 / 网申表单，调用**你自己的 DeepSeek API Key**，把保存在本地的简历智能匹配并一键填入，省去在几十个重复字段间反复复制粘贴。

> 本扩展参考「求职方舟 - 自动填简历插件」的交互与填写思路，**完全自研、开源可读、无登录、无会员、无后端**：简历和密钥只保存在你本机浏览器，点击填写时才直接发送给 DeepSeek 接口。

---

## 一、功能特性

- 右下角**悬浮球**（可拖动），展开后填写公司 / 职位，一键填写当前页。
- AI 自动识别字段含义（姓名、手机、邮箱、学历、学校、专业、起止时间、自我介绍、项目经历……），依据你的简历给出最合适的值。
- 兼容多种表单形态：
  - 原生 `input / textarea / select / radio / checkbox / contenteditable`
  - **React / Vue 受控组件**（用原生 setter + input/change 事件写入，能正确触发框架状态）
  - **Ant Design / Element UI** 的自定义下拉（Select）、单选 / 复选组、日期选择器（DatePicker）
  - 同源 `iframe` 内的表单会递归扫描
- 默认只填**尚未填写的空字段**，不会覆盖你已手填的内容（可在设置中开启“覆盖已有内容”）。
- 填写后绿色高亮被自动填充的字段，方便逐项核对。
- 分步式网申：每进入下一步填写页，再点一次即可。
- 单选 / 复选从页面选项中挑选；下拉框会自动展开浮层、在真实选项里匹配最接近的一项（扫描时取不到选项的懒加载下拉也能处理）；日期自动规范为 `YYYY-MM-DD`；手机号自动去掉 `+86` 和空格。
- 简历中没有的信息（如身份证、紧急联系人）**留空而不是编造**。

## 二、安装步骤（Chrome / Edge，开发者模式加载）

1. 解压本扩展压缩包，得到 `smart-autofill` 文件夹（内含 `manifest.json`）。
2. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车；Edge 输入 `edge://extensions/`。
3. 打开右上角（Edge 在左下角）的 **「开发者模式」** 开关。
4. 点击 **「加载已解压的扩展程序」**，选择第 1 步的 `smart-autofill` 文件夹。
5. 浏览器工具栏出现蓝色「智」图标即安装成功；建议点“固定”方便使用。

> 更新代码后，在扩展管理页点该扩展卡片上的「刷新」按钮，并刷新已打开的招聘网页。

## 三、配置（仅需一次）

1. 点击工具栏「智」图标 → **「设置 / 编辑简历」**（或右键图标 → 选项）。
2. **模型接口配置**
   - **API Key**：在 <https://platform.deepseek.com/> 注册、充值后创建，形如 `sk-xxxx`，粘贴到输入框。
   - **接口地址**：默认 `https://api.deepseek.com/v1`，一般无需修改；如用第三方兼容中转，填写其地址并在弹窗中授权。
   - **模型名称**：默认 `deepseek-v4-flash`（推理模型，思考较慢但更准）；也可改成你的账号可用的其它模型名。
   - `max_tokens` 默认 8192、超时 180000 毫秒：推理模型会先“思考”，这两个值不要调太小，否则可能返回空内容。
3. 点 **「测试连接」**，提示“连接成功”即可。
4. 在 **「我的简历」** 大文本框中粘贴简历（纯文本或 Markdown 均可），会自动保存。
5. （可选）填写默认公司 / 职位，勾选悬浮球、覆盖、高亮等偏好，保存。

## 四、使用方法

1. 打开招聘网站的简历填写 / 网申页面（如各校招官网、招聘平台的“完善简历”页）。
2. 点右下角蓝色悬浮球，必要时填上**公司**与**职位**（用于生成更有针对性的求职意向 / 自我介绍）。
3. 点 **「⚡ 一键填写本页」**；也可以点工具栏图标 →「立即填写本页」。
4. 观察状态提示：扫描字段 → AI 匹配（推理模型约 20–60 秒，耐心等待）→ 自动填写。
5. 多步表单：点页面上的“下一步 / 保存并继续”进入新的填写页后，**再点一次**一键填写。
6. **提交前务必人工逐项核对**，尤其是身份证号、起止日期、下拉、单选 / 复选、附件上传与验证码（这些控件不会自动处理）。

## 五、支持与不支持的控件

| 控件类型 | 是否自动填写 | 说明 |
| --- | --- | --- |
| 单行 / 多行文本、数字、邮箱、电话 | ✅ | 含 React/Vue 受控输入框、富文本 contenteditable |
| 原生下拉 / 单选 / 复选 | ✅ | AI 从页面选项中挑选最匹配项 |
| Ant Design / Element 下拉、单选组、复选组 | ✅（尽力匹配） | 自动展开浮层并点击对应选项 |
| AntD / Element 单日期选择器 | ✅（键盘录入 + 回车） | 日期**范围**（起止两个日期）建议手动选择 |
| 原生日期 `<input type=date/month>` | ✅ | 自动规范格式 |
| 文件 / 附件上传、验证码、密码框、搜索框 | ❌ | 主动跳过，避免误操作 |
| 跨域 iframe、级联地区选择器 | ⚠️ 部分 | 跨域框架受浏览器安全限制无法访问；级联控件可能需手动选择 |

## 六、隐私与安全说明

- API Key、简历、偏好仅保存在 `chrome.storage.local`（本机浏览器配置目录），不经过任何第三方服务器。
- 点击“一键填写”时，扩展会把**当前页字段结构 + 你的简历文本 + 公司/职位**直接发送到你配置的模型接口（默认 DeepSeek 官方）以获得填写结果；除此之外不发起任何网络请求。
- 扩展不收集、不上传你的浏览历史或投递数据。
- 源码全部在本文件夹内，可自行审计。

## 七、常见问题

**1. 点了没反应 / 提示“无法连接页面”？**
请刷新一下招聘网页再点；确认扩展已启用。SPA 单页应用切换路由后也建议刷新。

**2. 提示“未发现可填写字段”？**
当前视图没有可见的空字段。请先进入到具体的填写步骤；折叠面板需先展开；已填字段默认跳过。

**3. AI 返回空 / 提示正式回答为空？**
推理模型把输出额度用在了“思考”上。到设置里把 `max_tokens` 调到 8192 或更大后重试。

**4. 下拉 / 日期没填上？**
个别高度定制的控件（级联地区、自定义日期范围、虚拟滚动下拉）可能无法自动操作，状态条会列出需手动处理的字段名，手动补一下即可。

**5. 接口报 401 / 402？**
401 多为 Key 错误或失效；402 为余额不足，请到 DeepSeek 平台检查。

**6. 会乱填吗？**
AI 被严格要求只依据你的简历填写、不得编造，简历中没有的信息留空。但 AI 仍可能出错，**提交前请务必人工核对**，本工具只提升录入效率，最终内容由你确认。
