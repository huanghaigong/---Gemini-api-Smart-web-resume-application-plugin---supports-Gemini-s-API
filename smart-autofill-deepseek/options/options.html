智能网申 · AI 一键填简历

简历与密钥仅保存在本机浏览器，点击填写时才会发送给你配置的模型服务商。

① 模型接口配置

在 platform.deepseek.com 注册并创建 API Key。Key 只保存在本地 chrome.storage，不会上传到第三方。

② 我的简历

把简历内容粘贴到下面（纯文本或 Markdown 均可），AI 会严格依据这份简历填写，不会凭空编造。内容自动保存在本地。

③ 填写偏好

使用步骤

  1. 填好上方 API Key 并粘贴简历，点保存。
  2. 打开招聘网站的简历 / 网申填写页面。
  3. 点右下角悬浮球（或扩展图标 →「立即填写本页」），必要时填上公司与职位。
  4. 等待 AI 识别并自动填入，逐页（多步表单点“下一步”后）重复点击即可。
  5. 提交前请务必人工核对，尤其是身份证号、日期、下拉与单选项。
