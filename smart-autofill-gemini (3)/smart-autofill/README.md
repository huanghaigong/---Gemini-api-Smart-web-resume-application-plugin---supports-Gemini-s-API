# 智能网申 · AI 一键填简历（Chrome 扩展 · Gemini 版）

自动识别各大厂招聘官网的简历 / 网申表单，调用**你自己的 Gemini API Key**，把保存在本地的简历智能匹配并一键填入，省去在几十个重复字段间反复复制粘贴。

> 本扩展参考「求职方舟 - 自动填简历插件」的交互与填写思路，**完全自研、开源可读、无登录、无会员、无后端**：简历和密钥只保存在你本机浏览器，点击填写时才直接发送给 Gemini 官方接口（generativelanguage.googleapis.com）。

---

## 一、功能特性

- 右下角**悬浮球**（可拖动），展开后填写公司 / 职位，一键填写当前页。
- AI 自动识别字段含义（姓名、手机、邮箱、学历、学校、专业、起止时间、自我介绍、项目经历……），依据你的简历给出最合适的值。
- 兼容多种表单形态：
  - 原生 `input / textarea / select / radio / checkbox / contenteditable`
  - **React / Vue 受控组件**（用原生 setter + input/change 事件写入，能正确触发框架状态）
  - **Ant Design / Element UI** 的自定义下拉（Select）、单选 / 复选组、日期选择器（DatePicker）
  - 同源 `iframe` 内的表单会递归扫描
- 默认只填**尚未填写的空字段**，不会覆盖你已手填的内容（可在设置中开启“覆盖已有内容”）。
- 填写后绿色高亮被自动填充的字段，方便逐项核对。
- 分步式网申：每进入下一步填写页，再点一次即可。
- 单选 / 复选从页面选项中挑选；下拉框会自动展开浮层、在真实选项里匹配最接近的一项（扫描时取不到选项的懒加载下拉也能处理）；日期自动规范为 `YYYY-MM-DD`；手机号自动去掉 `+86` 和空格。
- 简历中没有的信息（如身份证、紧急联系人）**留空而不是编造**。

## 二、安装步骤（Chrome / Edge，开发者模式加载）

1. 解压本扩展压缩包，得到 `smart-autofill` 文件夹（内含 `manifest.json`）。
2. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车；Edge 输入 `edge://extensions/`。
3. 打开右上角（Edge 在左下角）的 **「开发者模式」** 开关。
4. 点击 **「加载已解压的扩展程序」**，选择第 1 步的 `smart-autofill` 文件夹。
5. 浏览器工具栏出现蓝色「智」图标即安装成功；建议点“固定”方便使用。

> 更新代码后，在扩展管理页点该扩展卡片上的「刷新」按钮，并刷新已打开的招聘网页。

## 三、配置（仅需一次）

1. 点击工具栏「智」图标 → **「设置 / 编辑简历」**（或右键图标 → 选项）。
2. **获取 Gemini API Key（免费）**
   - 打开 <https://aistudio.google.com/apikey>，用 Google 账号登录。
   - 点击 **「Create API key」**，复制生成的密钥（形如 `AIza...`），粘贴到扩展设置里。
   - 免费额度即可满足日常使用；用量大的话到 Google AI Studio 的「Usage」页查看配额。
3. **模型接口配置**
   - **API Key**：粘贴上一步的 `AIza...` 密钥。
   - **接口地址**：默认 `https://generativelanguage.googleapis.com/v1beta`，一般无需修改。
   - **模型名称**：默认 `gemini-3.6-flash`（速度快、免费额度内够用）。注意：2026 年起 `gemini-2.5-flash` 等旧模型对新账号已不可用，若遇到 404 提示，按接口返回提示改用新模型名（如 `gemini-3.6-flash`），其它可用模型以你 Google AI Studio 账号展示为准。
   - **备用模型**：默认 `gemini-3.5-flash, gemini-3.5-flash-lite`，主模型繁忙（429/503）或不可用（404）时会**自动按顺序切换**，无需手动改。可在设置里按需增删（逗号分隔）。
   - `maxOutputTokens` 默认 8192、超时 180000 毫秒：不要调太小，否则长简历 + 多字段可能被截断。
4. 点 **「测试连接」**，提示“连接成功”即可。
5. 在 **「我的简历」** 大文本框中粘贴简历（纯文本或 Markdown 均可），会自动保存。
6. （可选）填写默认公司 / 职位，勾选悬浮球、覆盖、高亮等偏好，保存。

## 四、使用方法

1. 打开招聘网站的简历填写 / 网申页面（如各校招官网、招聘平台的“完善简历”页）。
2. 点右下角蓝色悬浮球，必要时填上**公司**与**职位**（用于生成更有针对性的求职意向 / 自我介绍）。
3. 点 **「⚡ 一键填写本页」**；也可以点工具栏图标 →「立即填写本页」。
4. 观察状态提示：扫描字段 → AI 匹配（约 10–60 秒，耐心等待）→ 自动填写。
5. 多步表单：点页面上的“下一步 / 保存并继续”进入新的填写页后，**再点一次**一键填写。
6. **提交前务必人工逐项核对**，尤其是身份证号、起止日期、下拉、单选 / 复选、附件上传与验证码（这些控件不会自动处理）。

## 五、支持与不支持的控件

| 控件类型 | 是否自动填写 | 说明 |
| --- | --- | --- |
| 单行 / 多行文本、数字、邮箱、电话 | ✅ | 含 React/Vue 受控输入框、富文本 contenteditable |
| 原生下拉 / 单选 / 复选 | ✅ | AI 从页面选项中挑选最匹配项 |
| Ant Design / Element 下拉、单选组、复选组 | ✅（尽力匹配） | 自动展开浮层并点击对应选项 |
| AntD / Element 单日期选择器 | ✅（键盘录入 + 回车） | 日期**范围**（起止两个日期）建议手动选择 |
| 原生日期 `<input type=date/month>` | ✅ | 自动规范格式 |
| 文件 / 附件上传、验证码、密码框、搜索框 | ❌ | 主动跳过，避免误操作 |
| 跨域 iframe、级联地区选择器 | ⚠️ 部分 | 跨域框架受浏览器安全限制无法访问；级联控件可能需手动选择 |

## 六、隐私与安全说明

- API Key、简历、偏好仅保存在 `chrome.storage.local`（本机浏览器配置目录），不经过任何第三方服务器。
- 点击“一键填写”时，扩展会把**当前页字段结构 + 你的简历文本 + 公司/职位**直接发送到 Gemini 官方接口（generativelanguage.googleapis.com）以获得填写结果；除此之外不发起任何网络请求。
- 扩展不收集、不上传你的浏览历史或投递数据。
- 源码全部在本文件夹内，可自行审计。

## 七、常见问题

**1. 点了没反应 / 提示“无法连接页面”？**
请刷新一下招聘网页再点；确认扩展已启用。SPA 单页应用切换路由后也建议刷新。

**2. 提示“未发现可填写字段”？**
当前视图没有可见的空字段。请先进入到具体的填写步骤；折叠面板需先展开；已填字段默认跳过。

**3. AI 返回空 / 提示正式回答为空？**
可能是输出 token 额度被用尽或内容被安全策略拦截。到设置里把 `maxOutputTokens` 调到 8192 或更大后重试。

**4. 下拉 / 日期没填上？**
个别高度定制的控件（级联地区、自定义日期范围、虚拟滚动下拉）可能无法自动操作，状态条会列出需手动处理的字段名，手动补一下即可。

**5. 接口报 400 / 403 / 404 / 429 / 503？**
400 多为模型名写错或请求参数问题；403 多为 API Key 无效或未开启对应模型；404 多为模型名不可用（如旧版 gemini-2.x 对新账号已停用），请按接口返回的提示改用新模型名（如 `gemini-3.6-flash`）。429 / 503 是模型高峰期临时过载，扩展已内置**自动重试（最多 3 次、指数退避）+ 备用模型自动切换**，稍等片刻再点一次即可；仍失败可在设置里调整备用模型列表。

**6. 会乱填吗？**
AI 被严格要求只依据你的简历填写、不得编造，简历中没有的信息留空。但 AI 仍可能出错，**提交前请务必人工核对**，本工具只提升录入效率，最终内容由你确认。

## 九、技术说明：Gemini 接口调用方式

本扩展使用 Gemini 官方 REST 接口 `generateContent`（v1beta）：

- 请求地址：`POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`
- 鉴权方式：请求头 `x-goog-api-key: <你的 API Key>`（也可以改为 URL 参数 `?key=`）
- 请求体：

```json
{
  "systemInstruction": { "parts": [{ "text": "网申填写助手系统提示词…" }] },
  "contents": [{ "role": "user", "parts": [{ "text": "字段结构 + 简历 JSON…" }] }],
  "generationConfig": { "temperature": 0.1, "maxOutputTokens": 8192 }
}
```

- 返回解析：`data.candidates[0].content.parts[*].text` 拼接后按 `{"values":[...]}` 提取。

## 十、可选：Cloudflare Worker 中转（国内免代理直连 Gemini）

如果你在国内容器内无法直连 `generativelanguage.googleapis.com`，可以用**自己的域名 + Cloudflare Worker** 做服务端中转，本机无需开代理：

- 部署一份 Worker（转发 `/v1beta/*` 到 Google），把「接口地址 Base URL」改为 `https://你的域名/v1beta`
- 中转模式支持两种：
  - **模式 A（推荐）**：Worker 环境变量配 `GEMINI_API_KEY` + `RELAY_TOKEN`，插件「API Key」留空、填「中转令牌」（扩展 ≥ 1.3.0）
  - **模式 B（透传）**：插件照常填 API Key，Worker 原样转发
- 完整部署步骤（含 Dashboard 图文操作、测试命令、故障排查）见随包附带的 `gemini-api-relay/部署指南.md`

> 原理：请求先到 Cloudflare 边缘服务器（全球节点可直连 Google），由 Worker 代你转发给 Gemini，因此你本机不需要保持代理开启。纯静态网页无法实现此效果。
